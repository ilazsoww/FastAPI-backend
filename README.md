## Будущие перспективы и развитие (Roadmap)

### Валидация и Архитектура
- [ ] Внедрение Pydantic-схем для строгой типизации DTO.
- [ ] Разделение бизнес-логики (Services), маршрутов (Routers) и моделей (Models).

### Работа с базами данных
- [ ] Настройка миграций **Alembic** для управления изменениями схем БД.
- [ ] Добавление связей между таблицами (One-to-Many / Many-to-Many).
- [ ] Полноценная реализация **CRUD**-операций (Create, Read, Update, Delete).

### Machine Learning & Data Science
- [ ] Интеграция ML-модели для анализа входящих данных.
- [ ] Предобработка данных с помощью **Pandas** и **NumPy**.
- [ ] Создание REST API эндпоинта для выдачи предсказаний модели (Inference API).

Preferably CRUD, Machine Learning ways.
